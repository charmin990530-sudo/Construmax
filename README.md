# Construmax

Sitio estático de muestra para una constructora en Bogotá. Lo hice sin frameworks ni proceso de build, con HTML, CSS y JavaScript puros.

## Incluye

- Inicio, empresa, proyectos y contacto.
- Catálogo filtrable de proyectos.
- Diseño responsive y navegación por hash.

## Ejecutar

Abre `index.html` directamente o usa cualquier servidor estático:

```bash
npx serve .
```

## Demo

[Ver Construmax en Vercel](https://construmax-murex.vercel.app/)
